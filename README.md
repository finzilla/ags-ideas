# AGS — Карта инвестиционных идей

Интерактивная матрица инвестиционных идей Abylai Global Solutions.

Данные загружаются из Google Sheets в реальном времени.

## Функционал

- 📊 Матрица инвест-идей с фильтрами (риск, источник, статус, сектор)
- 💼 Формирование портфеля с ребалансировкой
- 📈 Автоматический расчёт риска (upside/downside)
- 🍩 Диаграмма распределения по секторам
- 📥 Экспорт портфеля в CSV
- 💡 Форма для предложения новых идей

## Деплой

Статический сайт на GitHub Pages. Обновление данных — через Google Sheets.
